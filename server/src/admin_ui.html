StrongBox resilient mode When the B side lacks StrongBox capability, automatically downgrade to B-side TEE issuance (Android's standard silent-downgrade behavior)

Enable resilient mode
Loading…

When enabled: if a B-side device reports StrongBox unsupported / no pre-provisioned key, the server automatically downgrades the request to TEE level and resends it to the B side, and returns an explicit downgrade marker to compatible A sides; the certificate chain and KeyCharacteristics both honestly report TRUSTED_ENVIRONMENT (never impersonating StrongBox). When disabled, strict native semantics are kept and StrongBox failures follow the server three-tier fallback.
